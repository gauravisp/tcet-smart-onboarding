# 🚀 LaunchPad — Smart Student Onboarding Agent

LaunchPad is an AI-powered student onboarding portal 
built for engineering colleges to simplify and automate 
the entire onboarding journey — from admission confirmation 
to the first day of class. Built for the TCS InnovGenius 
Hackathon 2026 by Team TechTrioz, TCET.

## 🎯 Problem
New engineering students face confusion during onboarding —
scattered information, missed deadlines, unverified documents, 
and zero guidance. Colleges struggle with manual follow-ups 
and administrative overhead.

## 💡 Solution
LaunchPad brings everything into one intelligent platform. 
Students get a personalized checklist, real-time progress 
tracking, document upload, and a 24/7 AI chatbot to answer 
queries instantly. Admins get a powerful dashboard to monitor 
every student, verify documents, and send broadcast emails 
with one click.

## ✨ Key Features
- 🔐 Secure login and registration for students and admins
- ✅ Personalized onboarding checklist with progress tracking
- 📄 Document upload and cloud storage via Cloudinary
- ✔️ Admin document verification with instant student notification
- 🤖 AI chatbot for 24/7 query resolution
- 📧 Automated deadline reminder emails via Nodemailer
- 📢 Admin broadcast emails to all students at once
- 📊 Admin dashboard with real-time student progress monitoring

## 🛠️ Tech Stack
Frontend → React.js  
Backend → Node.js + Express.js  
Database → MongoDB Atlas  
Storage → Cloudinary  
Email → Nodemailer + Gmail  
Auth → JWT + bcrypt  
Deployed on → Vercel + Render
